# Lecture outline — 204111 Data Structures · Week 8: Stacks

> ตัวอย่างโน้ตเตรียมสอน — จุดตั้งต้นก่อนให้ AI ทำเป็นสไลด์บรรยาย

## สไลด์ 1 — Stack คืออะไร

- โครงสร้างข้อมูลแบบ LIFO — Last In, First Out
- ทำงานเหมือนกองจาน: วางทับบนสุด แล้วหยิบจากบนสุด
- การทำงานหลัก 2 อย่าง: `push` (วางบน) และ `pop` (หยิบบน)
- ดูข้อมูลบนสุดโดยไม่ต้องหยิบออก: `peek`

## สไลด์ 2 — ทำไมต้องมี Stack

- call stack — ทุกครั้งที่เรียกฟังก์ชัน ระบบก็ push frame ใหม่
- undo ในโปรแกรมแก้ไข — กด undo = pop รายการล่าสุด
- ตรวจว่าวงเล็บ `()` `[]` `{}` จับคู่ถูกไหม

## สไลด์ 3 — ตัวอย่าง: ตรวจวงเล็บ

- อ่านทีละตัวอักษร: เจอวงเล็บเปิด → push
- เจอวงเล็บปิด → pop แล้วเทียบคู่
- จบแล้ว stack ต้องว่างเปล่า ถึงจะถูกต้อง
- ตัวอย่างผ่าน: `{[()]}` · ตัวอย่างพลาด: `{[(])}`
